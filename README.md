# Projetos Iniciais em PHP

[![GitHub](https://img.shields.io/badge/Reposit%C3%B3rio-GitHub-black?style=for-the-badge&logo=github)](https://github.com/LeandroStanger/Projetos-Iniciais-PHP)

## Descrição

Este repositório contém projetos introdutórios desenvolvidos em PHP, organizados em aulas sequenciais. Cada aula apresenta scripts que demonstram conceitos fundamentais da linguagem, como estruturas condicionais, manipulação de variáveis e lógica de programação. O conteúdo é ideal para iniciantes que desejam consolidar os fundamentos do desenvolvimento web back-end com PHP.

## Tecnologias Utilizadas

- PHP (versão 7 ou superior)
- Servidor web local (Apache, Nginx) ou PHP Built-in Server

## Como Executar o Projeto

### Pré-requisitos

- PHP instalado (versão 7 ou superior)
- Servidor web local (opcional, pode usar o servidor embutido do PHP)

### Passo a Passo

1. **Clone o repositório** (ou baixe o código ZIP):
   ```bash
   git clone https://github.com/LeandroStanger/Projetos-Iniciais-PHP.git
   cd Projetos-Iniciais-PHP
   ```

2. **Navegue até a pasta da aula desejada** (por exemplo, Aula1):
   ```bash
   cd Aula1
   ```

3. **Execute o script PHP**:
   - Usando o servidor embutido do PHP:
     ```bash
     php -S localhost:8000
     ```
     Em seguida, acesse `http://localhost:8000/nome_do_arquivo.php` no navegador.
   - Ou execute diretamente no terminal (para scripts sem interface web):
     ```bash
     php nome_do_arquivo.php
     ```
